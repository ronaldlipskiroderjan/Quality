# Artefatos de agentes

Esta pasta reúne arquivos produzidos por agentes e ferramentas de apoio ao desenvolvimento.

## Conteúdo local

- [AGENTE_ESPECIALISTA_TESTES_QUALIDADE.md](AGENTE_ESPECIALISTA_TESTES_QUALIDADE.md): perfil operacional permanente para planejamento, especificação, execução e revisão de testes do projeto.
- `impeccable/`: estado de trabalho, revisões, capturas e perfis temporários usados no refinamento da interface.
- `impeccable-frontend/`: análises e capturas específicas do frontend.
- `regions.json`: regiões de interface registradas durante inspeções visuais.

Esses artefatos são gerados novamente quando necessário e, por isso, não são versionados. A documentação permanente de produto e design fica nas pastas `Produto` e `Design`.
